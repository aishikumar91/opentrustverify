# OTV-0004 Verification API

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

HTTP API for claims, verdict fetch, signature check, tenant admin, webhooks, and health.

## Normative base

- Production: `https://otv.poptrust.me` (API paths under `/v1`)
- Local: `http://localhost:4080`
- OpenAPI: `GET https://otv.poptrust.me/api/docs`, `GET /v1/openapi.json`

## Auth

| Mode | Use |
|------|-----|
| API key (`Authorization: Bearer` or `X-OTV-Api-Key`) | verify, webhooks, usage |
| Session cookie `otv_session` or `X-OTV-Session` | dashboard org/project/keys/audit/billing |
| None | health, ready, metrics, catalogs, GET verdict, signature verify, JWKS |

Keys stored as SHA-256. See `docs/API_SPEC.md` and `docs/api/API_REFERENCE.md`.

## Errors

400 validation / unsafe webhook; 401 unauthorized; 404 verdict missing; 429 rate limit; 501 OIDC unconfigured; 503 not ready.
