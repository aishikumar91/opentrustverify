# OTV-0006 Wallet Profile

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

How a wallet MUST present OTV so users do not treat raw chain activity as spendable funds.

## Requirements

1. Call `OpenTrustVerify.verifyIncomingTransfer` (or equivalent HTTP) before showing “received / spendable”.
2. Map statuses per `docs/sdk/SDK_GUIDE.md` — never color-only.
3. Show evidence on demand.
4. If `MOCK_ADAPTER` risk is present, label the result as demo/offline.
5. Do not embed signing keys in the client.

TypeScript: `@otv/sdk-core` + `@otv/sdk-react`. Dart: `packages/sdk-flutter`. Conformance: `pnpm conformance`.
