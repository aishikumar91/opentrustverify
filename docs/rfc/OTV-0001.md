# OTV-0001 Problem Statement

**Status:** Draft  
**Version:** 0.1.0

## Abstract

Specification draft for OpenTrust Verify — Problem Statement.

## Motivation

Support an interoperable verification layer that does not collapse blockchain activity with spendable funds.

See cross-linked docs:

## Compatibility

Versioned independently. Breaking changes require a new RFC revision.

## Security Considerations

Deterministic verification only. Signed verdicts. No client-held signing keys.
