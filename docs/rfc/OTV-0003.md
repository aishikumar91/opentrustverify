# OTV-0003 Verdict Schema

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

`otv.verdict.v1` is the public, signed artifact of a verification.

## Required fields

See `docs/VERDICT_SPEC.md` and `packages/verdict-schema`. Notable rules:

- `schema` MUST be `otv.verdict.v1`
- `signature` is hex-encoded Ed25519 over SHA-256 of canonical JSON (signature field omitted)
- `evidence` MUST be non-empty
- `confidence` is `[0, 1]` and MUST be capped at `0.95` on mock adapters
- `kid` identifies the verifying key

## Canonicalization

Object keys sorted recursively; `signature` excluded; JSON.stringify of the sorted structure; SHA-256; Ed25519.

## Compatibility

Unknown statuses MUST fail parse. Additional evidence types require a schema revision or a documented extension object (not used in v1).
