# OTV-0008 Chain Adapter

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

All RPC goes through `ChainAdapter`. Engine code never constructs JSON-RPC itself.

## Interface

Documented in `CHAIN_ADAPTER_SPEC.md` and `packages/chain-adapters`.

## Ethereum

- No `ETH_RPC_URL` → `MockChainAdapter`
- With URL → live `eth_getTransactionByHash`, receipt, logs, `balanceOf`, block number, finality confirmations
- Mock path MUST attach `MOCK_ADAPTER` at the API layer and cap confidence

Future chains implement the same interface; they are out of MVP production coverage.
