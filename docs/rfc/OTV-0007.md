# OTV-0007 Explorer Profile

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

Explorers MAY add OTV as an additive panel. Raw chain data MUST remain visible and unlabeled as “verified” unless an OTV verdict says so.

## Components

`VerificationBadge`, `TransactionTrustPanel`, `EvidenceTimeline`, `VerdictCard`, `SignatureVerification` in `@otv/ui`.

Label groups **Blockchain Explorer Data** vs **OTV VERIFICATION**. See `EXPLORER_INTEGRATION.md`.
