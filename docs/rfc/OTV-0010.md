# OTV-0010 Conformance

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

Automated gates for “OTV Compatible” implementations of the mock path. Certification marks require separate authorization.

## Suites

Implemented in `tests/conformance` (`pnpm conformance`):

1. Verdict schema parse; unknown status rejected
2. Transition rules
3. Sign/verify round-trip; tamper fails
4. SPENDABLE includes required evidence types
5. Mock adapter is deterministic for the demo hash
6. API unauthorized verify → 401 (`@otv/api` tests)

## Run

```bash
pnpm --filter './packages/*' run build
pnpm conformance
pnpm --filter @otv/api run test
pnpm demo
```

Full harness spec: `docs/conformance/OTV-0010-CONFORMANCE.md`.
