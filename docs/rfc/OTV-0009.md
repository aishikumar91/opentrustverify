# OTV-0009 Security Considerations

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

Controls that MUST hold for a hosted OTV deployment.

## Controls

- Hashed API keys; scrypt passwords; hashed session tokens
- Helmet, CORS, Redis-backed rate limits when Redis is configured
- Webhook SSRF deny-list + HMAC + idempotency keys + durable retries
- Signing keys on disk / wrapped; never in clients
- Parameterized SQL (`pg` bind parameters)
- `/v1/ready` fails closed if Postgres or the active kid is unavailable
- No LLM in the spendability path

See `SECURITY.md`, `docs/THREAT_MODEL.md`, `docs/security/KMS.md`.
