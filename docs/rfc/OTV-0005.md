# OTV-0005 Signed Verdict

**Status:** Accepted  
**Version:** 0.1.0

## Abstract

How a verifier attests a verdict so third parties can check it without calling OTV’s private keys.

## Algorithm

1. Canonical JSON (sorted keys, drop `signature`)
2. SHA-256 digest
3. Ed25519 signature, **hex** encoded (v1; not base64url)
4. Attach `kid` + `signature`

Verify: `POST /v1/verdicts/verify` or `verifyPayload` in `@otv/crypto-signatures`. Public keys: `GET /v1/keys`.

## Key lifecycle

File keystore in `OTV_KEYS_DIR`. Optional AES-256-GCM wrap with `OTV_KMS_MASTER_KEY`. Rotation marks previous `kid` as `rotated`. See `docs/security/KMS.md`.
